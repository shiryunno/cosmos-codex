title: Lanceira

| Característica      | Valor                                                                          |
| ------------------- | ------------------------------------------------------------------------------ |
| Casco               | 100 HP                                                                         |
| HP por Sistema      | 20                                                                             |
| CA                  | 16                                                                             |
| Postos              | 3 (Piloto, Artilharia Leve, Carta)                                             |
| Espaços de Módulo     | 2                                                                              |
| Espaços de Carga      | 1 grande OU 4 pequenos                                                         |
| Tamanho aproximado  | 20-30 metros (caça monoplace estendido)                                        |

Canhão Improvisado: a Lanceira pode equipar o módulo Canhão Improvisado, ganhando o posto de Artilharia Pesada. Quando o Artilharia dispara Tiro de Potência Máxima ou Tiro Forçado, o Piloto perde sua Ação Principal de Manobra naquele turno - o recuo desalinha a trajetória e ele precisa recalcular. Estabilização e Reação do Piloto continuam disponíveis.
